# Qianxv-search-mcp v2.10 节点配置说明

本说明适用于本发行目录中的 `config.json`。首次使用时将同目录的
`config.example.json` 复制为 `config.json`，填写自己的凭证；已有私有配置时
不要覆盖。配置须与 exe 同目录，修改后重启服务。私有配置和日志不要上传或分发。

模板预置 Tavily 搜索、AnySearch 抓取，并在数组末尾启用本机搜索与抓取，密钥为空。
云节点需配置自己的凭证；本机节点无需凭证但仍需联网，也可禁用云节点仅使用本机节点。
至少配置一个可用搜索节点；使用 `extract` 时还须配置可用抓取节点。

## 字段与调用顺序

- `nodes`：非空搜索节点数组，排列顺序决定搜索故障转移顺序。
- `extract_nodes`：抓取节点数组，排列顺序决定抓取故障转移顺序；可省略，
  提供时须为非空数组，不能为 `null`。不配置可用抓取节点时，`extract` 返回所有节点不可用。
- `failover.breaker_seconds`：失败节点的熔断窗口，默认 60 秒，须为有限非负数；`0` 禁用熔断。窗口内跳过该节点；冷却结束后只允许一个恢复探测。
- `failover.search_timeout_seconds` / `failover.extract_timeout_seconds`：可选的搜索/抓取整次调用总预算，须为有限正数；省略时按对应启用节点的 `timeout_seconds` 合计。模板省略这两个字段。
- 根配置与 `failover` 须为对象。

每个节点的字段（超时以秒为单位）：

| 字段 | 含义 |
|---|---|
| `name` | 节点名称，同一数组内须非空且唯一 |
| `type` | 下表中的搜索或抓取类型，不能混放到另一类数组 |
| `enabled` | 必须为 JSON 布尔值，默认 `true`；使用 `false` 停用节点 |
| `api_key` | 自己的供应商凭证；模板留空，不能据此认为节点可用 |
| `timeout_seconds` | 有限正数，`local_extract` 默认 15 秒，其余默认 10 秒；限制 HTTP 网络阶段及整个节点执行过程 |
| `options` | 节点选项对象；云节点调用时须配置非空 `endpoint`；本机节点无需端点，选项见下文 |

服务按数组顺序串行尝试启用节点。节点超时、网络/HTTP/鉴权/业务错误、
配额耗尽或空结果时自动尝试下一节点。搜索空结果不熔断；至少一个节点正常响应但所有结果为空时，正常返回“未找到相关结果”。全部节点真实失败或总预算耗尽时返回 MCP 工具错误（`isError: true`）。
每个节点的执行上限取其超时与剩余总预算的较小值；预算耗尽后不再尝试后续节点。取消请求不触发熔断。
节点超时与总预算同时到期时，当前节点仍按超时记录熔断；因更短总预算被提前停止的节点不熔断。恢复探测自身超时会重新开始冷却，下一次请求跳过该节点。
全部节点禁用时服务仍可启动，但对应工具返回所有节点不可用。
供应商可能返回少于 `max_results` 请求数量的搜索结果。

## 搜索节点与端点

以下类型放入 `nodes`；云节点的 `options.endpoint` 填入对应端点，本机节点无需端点：

| `type` | `options.endpoint` | 凭证 |
|---|---|---|
| `tavily` | `https://api.tavily.com/search` | Tavily API Key |
| `anysearch` | `https://api.anysearch.com/v1/search` | 适配器允许不发送凭证，能否匿名使用由服务端决定 |
| `qianfan` | `https://qianfan.baidubce.com/v2/ai_search/web_search` | 千帆 API Key |
| `volc_ark` | `https://open.feedcoopapi.com/search_api/web_search` | 联网搜索 Custom 专用 API Key，不能用方舟 ark Key 替代 |
| `zhihu` | `https://developer.zhihu.com/api/v1/content/global_search` | 知乎数据开放平台 Access Secret |
| `local_search` | 无需配置 | 无需凭证，需联网 |

可选的 `options` 字段沿用各节点实现：

- `anysearch`：`zone`、`language`、`tag`。
- `qianfan`：`search_source`，默认 `baidu_search_v2`。

其他类型使用上表端点即可。免费额度、开通条件和计费以供应商控制台为准，
还须自行确认凭证、权限和余额。

## 抓取节点与端点

以下类型放入 `extract_nodes`：

| `type` | `options.endpoint` | 凭证 |
|---|---|---|
| `anysearch_extract` | `https://api.anysearch.com/v1/extract` | AnySearch API Key |
| `tavily_extract` | `https://api.tavily.com/extract` | Tavily API Key |
| `local_extract` | 无需配置 | 无需凭证，需联网 |

两种云抓取节点需要配置凭证，本机抓取无需凭证。抓取内容来自公开网页，不可信，仅作参考。
分页参数、快照有效期和容量限制见同目录 [安装说明](安装说明.md)。续读须连接同一个服务进程。

## 本机节点配置与网络

`local_search` 通过 [DDGS](https://pypi.org/project/ddgs/) 在本机访问搜索引擎，
`local_extract` 使用共享 `httpx` 客户端下载网页，再通过
[Trafilatura](https://trafilatura.readthedocs.io/) 在本机提取标题和 Markdown 正文。
两个节点均不使用 API key，仍需联网；只启用这两个节点也可运行。

- 将同目录模板中的本机节点追加到现有配置对应数组末尾，重启后即可兜底。
  保留已有云节点和凭证；不要用模板覆盖私有配置。
- 搜索默认超时 10 秒，`options.backend` 默认 `auto`（`all` 等价）。每次查询并发
  尝试当前 DDGS 版本启用的全部 text 引擎和 `bing_html`，返回首个非空有效结果；
  失败或空结果不会阻止其他引擎，全部失败时明确报告。所有尝试共享节点超时，
  不按测试机器固化可用引擎，也不将超时时间乘以引擎数量。
  DDGS 9.16.0 启用的 text 引擎为 `brave`、`duckduckgo`、`google`、`grokipedia`、
  `mojeek`、`startpage`、`wikipedia`、`yahoo`，实际可用性取决于运行机器的网络。
  `backend` 可指定单个引擎或逗号分隔的引擎列表（如 `duckduckgo,google,bing_html`），
  限定尝试范围；列表同样返回首个有效结果，单个引擎不会自动换用其他引擎。
  `options.region` 默认 `cn-zh`。未知和禁用引擎明确报错，`auto`/`all` 必须单独使用。
  `bing_html` 通过共享 `httpx` 下载 Bing HTML 并复用 DDGS 解析器；它独立于 DDGS
  已禁用的原生 `bing` 和 `yandex` text 后端。DDGS 代理通过 `DDGS_PROXY` 配置；`bing_html`
  和抓取沿用 `httpx` 的 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY`。
  `bing_html` 最多跟随 3 次重定向，仅允许 HTTPS 的 `www.bing.com` 或 `cn.bing.com`（默认端口或 443），拒绝带凭证的跳转 URL；缺少 Location 或超出次数时明确失败。
- 抓取默认超时 15 秒，单页下载上限 5 MiB，仅接受 HTTP/HTTPS HTML 页面，
  最多跟随 5 次重定向；到达上限后仍收到重定向会明确报错，流式响应会关闭；每一跳均检查 URL，拒绝 localhost、直接输入的非公网 IP
  和带凭证 URL。不向目标发送 API key 或 cookies。
- 抓取保留原始域名，使用标准 `httpx` 网络行为：有代理按代理配置请求，
  `NO_PROXY` 匹配时直连，没有代理时使用系统 DNS 和正常连接。
  支持 HTTP、HTTPS、SOCKS5 和 SOCKS5h 代理，代理认证沿用环境配置；
  目标域名可以由代理解析，不要求本机能够解析代理端目标。
  HTTP 和 HTTPS 均不设置机器专属 DNS 网段或代理信任名单。
  旧的 `trusted_dns_networks` 和 `trusted_proxy_urls` 选项不再影响请求。
  HTTPS 始终校验证书，目标和 HTTPS 代理分别使用各自的 TLS 身份；
  证书信任沿用 `httpx` 的 `SSL_CERT_FILE`、`SSL_CERT_DIR` 配置。
- 本机节点不运行 JavaScript，不处理登录或验证码，也不提供 PDF 提取、离线索引。
  搜索引擎不可达、限流或网页无法提取时会明确失败；本机兜底不能保证任意网站可用。
- 默认总预算会累加新增节点超时。若显式设置整次预算，须为末尾兜底留出时间；
  预算耗尽会停止尝试，客户端超时也应覆盖服务端预算。云节点原有超时仍决定兜底前
  的最长等待时间。
- DDGS 搜索和正文解析在线程中执行，Bing 下载使用异步 HTTP。取消或节点超时可结束等待，底层同步任务可能持续到
  自身执行结束或网络超时。

## 从旧版升级

v2.10 不再支持 `brightdata`。启动前从旧配置删除该类型的节点，保留其他节点与凭证。
需要本机兜底时，从本版模板追加对应节点；新增节点会计入默认总预算。
先停止旧进程，再整体替换 exe 与 `_internal/`，保留私有配置和日志。

## 配置排障

1. 配置加载失败：检查 JSON 语法、节点类型、数组及字段要求；删除旧 `brightdata` 节点。
2. 工具调用失败：检查节点开关、凭证、端点、额度，以及日志中的失败、超时与熔断原因。
3. 故障转移未到达末尾节点：检查整次调用预算，并让客户端超时覆盖服务端预算；预算耗尽后不会继续尝试。
4. 修改配置或代理环境后重启服务，保留已有凭证。日志位置与接入检查见 [安装说明](安装说明.md#工具日志与排错)。
