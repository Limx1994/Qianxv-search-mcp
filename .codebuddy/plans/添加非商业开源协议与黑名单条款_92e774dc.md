## Product Overview

为现有的本地搜索 MCP 服务项目（`d:/搜索MCP`）添加法律许可约束文件，明确项目的非商业使用限制，并禁止黑名单公司及其关联方使用本项目。

## Core Features

- 新建 `LICENSE` 文件，以 PolyForm Noncommercial 1.0.0 为协议基础，本项目仅可用于非商业用途
- 在 LICENSE 中附加黑名单条款，明确禁止以下公司及其关联公司、关联成员使用、复制、分发本项目：
- 连华科技
- 北京鼎兴达信息科技股份有限公司
- 黑名单「关联公司及成员」的认定保留最终解释权归版权方所有，以避免规避行为
- 在 `README.md` 末尾追加一节简短的「开源协议」说明，指向 LICENSE 并提示非商业限制与黑名单禁用条款

## Tech Stack Selection

- 纯文档任务，无需引入任何技术栈，仅涉及 Markdown 与纯文本文件编写

## Implementation Approach

- **协议基础**：采用 PolyForm Noncommercial 1.0.0 官方英文原文（专为源代码设计的标准非商业协议），保证法律表述的严谨性
- **附加条款**：在官方文本之后追加「Additional Terms — Noncommercial Restriction & Blacklist」（中文撰写，关键术语附英文对照），内容包括：

1. 非商业限制的中文重申
2. 黑名单公司列表（公司名称逐字准确，不添加猜测性的补充名称）
3. 关联公司及成员的禁用范围（含子公司、母公司、分支、控股、同一实际控制人、受雇/委托的成员等表述）
4. 关联关系认定的最终解释权归版权方（The Copyright Holder）

- **版权信息**：版权人名称未提供，使用「本项目版权所有者（The Copyright Holder）」+ 2026 年份表述，便于用户后续替换为真实姓名
- **README 更新**：仅在 README.md 末尾追加一个小节（`## 开源协议`），简述协议类型、非商业限制、黑名单禁用，并指向 LICENSE 文件；不改动 README 其他内容

## Implementation Notes

- `说明.txt` 含 API 密钥，严格不改动、不引用该文件
- 黑名单公司名称必须与用户提供的原文逐字一致，不做增删改（不猜测公司全称或补充工商注册名）
- LICENSE 编码使用 UTF-8（含中文附加条款），确保跨平台可读
- 不改动任何 Python 源码文件（`server.py`、`config_loader.py`、`search_router.py`、`providers/`、`tests/`），影响范围仅限两个文档文件
